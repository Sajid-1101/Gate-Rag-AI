About GateMind AI

Your intelligent AI powered assistant for GATE Computer Science preparation.

🤖 What is GateMind AI?

GateMind AI is a custom AI chatbot designed to help GATE CSE aspirants understand computer science concepts using trusted study material.

⚙️ How It Works

PDF Notes → Text Chunking → Vector Embeddings → FAISS Search → Gemini AI Response

The system uses Retrieval Augmented Generation (RAG), which allows the AI to search a custom knowledge base before generating answers.

🛠 Tech Stack

  • Frontend : React + CSS
  • Backend : Flask REST API
  • Language : Python
  • AI Model : Gemini API
  • Embeddings : HuggingFace Transformers
  • Vector Database : FAISS

📚 Knowledge Base

  • 2800+ pages of GATE CSE material
  • 6500+ vector chunks
  • Subject notes
  • Previous year questions
